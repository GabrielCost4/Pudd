# Fonte da assinatura

`LastoriaBoldRegular.otf` é a fonte indicada pela documentação do componente Signature do Spell UI: https://spell.sh/docs/signature.

O arquivo é servido localmente para renderizar a assinatura Pudd, sem solicitar a fonte a um serviço externo durante o login.


## Fonte da interface

Manrope variável, pesos 200–800, servida localmente em Manrope-variable.ttf com font-display swap. Origem: https://github.com/google/fonts/tree/main/ofl/manrope. Licença SIL Open Font License 1.1, preservada em Manrope-OFL.txt. A fonte tem formas geométricas abertas e diferencia títulos de leitura e metadados sem adicionar outra família à interface.
